## P0 — CRITICAL (Data Races, Memory Safety)

- [x] **#1 Data race on OpenAPI/docs/redoc caches** — `src/core/app.zig`
  - **Fix:** Added `cache_mutex: std.Thread.Mutex` field. All cache reads, writes, and invalidation now lock/unlock the mutex. (PR #1)

- [x] **#2 Data race on metrics registry** — `src/core/app.zig`
  - **Status:** FALSE POSITIVE — `metrics_registry.Registry` already has a `mutex` field and locks it in `observe()`, `deinit()`, and `renderPrometheus()`. No fix needed.

- [x] **#3 Thread spawn failure leaks running threads** — `src/runtime/server.zig`
  - **Fix:** Added `spawned` counter with `errdefer` that sets `force_stop` atomic flag and joins all already-spawned threads. (PR #1)

- [x] **#4 Missing `errdefer` in `addMiddleware`** — `src/core/app.zig`
  - **Fix:** Added `errdefer self.allocator.free(name);` between the dupe and the append. (PR #1)

- [x] **#5 Missing `errdefer` in `eventStream`** — `src/http/response.zig`
  - **Fix:** Added `errdefer response.deinit(allocator);` after constructing the Response. (PR #1)

- [x] **#6 OpenAPI `$ref` paths not JSON-escaped** — `src/openapi/generator.zig`
  - **Fix:** Added `writeJsonStringContent` helper. All three `writeComponentXxxRef` functions now use it. (PR #1)

- [x] **#12 `Connection.deinit` is a no-op** — `src/runtime/websocket.zig`

- [x] **#13 `WebSocketSession.close` swallows error** — `src/testing/testclient.zig`

## P0 — CRITICAL (Data Races, Memory Safety)

- [x] **#1 Data race on OpenAPI/docs/redoc caches** — `src/core/app.zig:36-38, 471-483`
  - `openapi_cache`, `docs_cache`, `redoc_cache` accessed from concurrent worker threads without synchronization. Check-then-act pattern causes duplicate generation, memory leak (overwritten pointer), and potential use-after-free when `invalidateGeneratedCaches()` runs while a response references the cache.
  - **Fix:** Added `cache_mutex: std.Thread.Mutex` field. All cache reads (`openapi()`, `docsHtml()`, `redocHtml()`), writes, and invalidation now lock/unlock the mutex.

- [x] **#2 Data race on metrics registry** — `src/core/app.zig:1427`
  - `self.metrics.observe(...)` called from concurrent request handlers.
  - **Status:** FALSE POSITIVE — `metrics_registry.Registry` already has a `mutex` field and locks it in `observe()`, `deinit()`, and `renderPrometheus()`. No fix needed.

- [x] **#3 Thread spawn failure leaks running threads** — `src/runtime/server.zig:60-63`
  - If thread N of M fails to spawn, threads 0..N-1 are already running but never joined. `state` (stack-allocated in `serve`) goes out of scope → use-after-free in running workers.
  - **Fix:** Added `spawned` counter. `errdefer` sets `force_stop` atomic flag and joins all already-spawned threads. Added `force_stop: std.atomic.Value(bool)` to `ServeState`, checked in `shouldTerminate`.

- [x] **#4 Missing `errdefer` in `addMiddleware`** — `src/core/app.zig:356-357`
  - In the `Middleware` struct branch, `name` allocation has no `errdefer` before the `append` call. OOM on `append` leaks `name`.
  - **Fix:** Added `errdefer self.allocator.free(name);` between the dupe and the append.

- [x] **#5 Missing `errdefer` in `eventStream`** — `src/http/response.zig:125-133`
  - If the second `setHeader` fails (OOM), the `payload` (owned_body) and first header allocation leak. No `errdefer response.deinit(allocator)`.
  - **Fix:** Added `errdefer response.deinit(allocator);` after constructing the Response.

- [x] **#6 OpenAPI `$ref` paths not JSON-escaped** — `src/openapi/generator.zig:1244-1263`
  - Component names for parameters, request bodies, and responses are written directly into JSON strings without escaping. A name containing `"` or `\` produces invalid JSON.
  - **Fix:** Added `writeJsonStringContent` helper that escapes `"`, `\`, `\n`, `\r`, `\t`. All three `writeComponentXxxRef` functions now use it for the component name.

## P1 — HIGH (Bugs, Structural)

- [ ] **#7 `closeWithCode` duplicated branches + uses `c_allocator`** — `src/runtime/websocket.zig:118-151`
  - `.raw` and `.synthetic` branches are byte-for-byte identical. Both use `std.heap.c_allocator` for a buffer that's at most 127 bytes (RFC 6455 limits close reason to 123 bytes).
  - **Fix:** Remove the switch; use a stack buffer `var buf: [2 + 123]u8 = undefined;`.

- [ ] **#8 `MessageQueue` never compacts consumed messages** — `src/runtime/websocket.zig:465-507`
  - `read_index` advances but old messages stay in the `ArrayList`. Over long-lived WebSocket connections → unbounded memory growth.
  - **Fix:** After `pop`/`popTimed`, if `read_index > items.len / 2`, shift remaining messages down and reset `read_index`.

- [ ] **#9 `workspaceFingerprint` nondeterministic** — `src/cli/main.zig:1022-1041`
  - `dir.walk()` does not guarantee deterministic order across platforms. Hash changes for identical file trees → phantom dev-mode restarts.
  - **Fix:** Collect walker output into a sorted array, then hash.

- [ ] **#10 Hardcoded macOS TLS paths** — `build.zig:174-196`
  - Only `/opt/homebrew/` and `/usr/local/` probed. Missing: Linux pkg-config, NixOS, Alpine, CI environments. Cross-compilation broken.
  - **Fix:** Add build option `b.option([]const u8, "openssl-prefix", ...)` and/or pkg-config lookup.

- [ ] **#11 `withStatus` ownership footgun** — `src/http/response.zig:136-140`
  - Bitwise copies Response including `owned_body` pointer. If original and copy both have `deinit` called → double-free.
  - **Fix:** Document ownership transfer, or change to `*Response` mutation.

- [ ] **#12 `Connection.deinit` is a no-op** — `src/runtime/websocket.zig:153-156`
  - Will silently leak if `Connection` ever gains owned state.
  - **Fix:** Add a comment explaining the intentional no-op, or null out fields for debug safety.

- [ ] **#13 `WebSocketSession.close` swallows error** — `src/testing/testclient.zig:92`
  - `catch {}` on `closeWithCode`. Inconsistent with `closeWithCode` method on line 96-101 which propagates.
  - **Fix:** At minimum log the error.

## P2 — MEDIUM (Code Quality, Duplication, Performance)

- [ ] **#14 Silent `catch {}` on `setHeader`** — `src/core/app.zig` (13+ instances)
  - Lines 1615, 1617, 1639, 1641, 1673-1678, 1683-1688, 1700, 1734-1749, 1761, 2479, 2485.
  - **Fix:** Replace with `catch |err| { std.log.debug("setHeader failed: {s}", .{@errorName(err)}); }`.

- [ ] **#15 `c_allocator` hardcoded in hot paths** — `server.zig:57,127-130`, `websocket.zig:132,144`, `injector.zig:635-652`
  - Bypasses `std.testing.allocator` leak detection and prevents allocator injection.
  - **Fix:** Accept allocator parameter where feasible; use stack buffers for small allocations.

- [ ] **#16 `runDependencyCleanups` short-circuits on first error** — `src/http/request.zig:613-622`
  - If cleanup[0] fails, cleanup[1..N] never run → resource leak.
  - **Fix:** Catch errors, continue running remaining cleanups, return first error at end.

- [ ] **#17 `patternMatches` silently degrades** — `src/core/injector.zig:630-633`
  - When POSIX regex compilation fails, falls back to naive literal matcher (handles only `^`, `$`, literals). No log message.
  - **Fix:** Add `std.log.warn` when regex compilation fails.

- [ ] **#18 `formAsLeaky` god function (71 lines)** — `src/http/request.zig:379-449`
  - Mixes comptime introspection, per-field decoding, validation issue construction (repeated 4x), default value resolution.
  - **Fix:** Extract `failValidation` helper and field-parsing helper.

- [ ] **#19 `xxxAs` accessor duplication (4 copies)** — `src/http/request.zig:216-322`
  - `cookieAs`, `queryAs`, `paramAs`, `headerAs` are structurally identical (~80 lines total).
  - **Fix:** Create generic `typedAccessor` function parameterized by location and accessor fn.

- [ ] **#20 Validation issue construction repeated 11 times** — `src/core/injector.zig`
  - Same `addValidationIssue` + `return error.ValidationFailed` block.
  - **Fix:** Extract `failValidation(req, location, field, message, issue_type, input)` helper.

- [ ] **#21 `invokeInjected` vs `invokeWebSocketInjected` near-identical** — `src/core/injector.zig:124-170`
  - Only difference: WS version takes extra `conn` param and sets `context.ws_conn`.
  - **Fix:** Create generic `invokeWithContext` function.

- [ ] **#22 `validateNumericConstraints` 4 copy-paste blocks** — `src/core/injector.zig:413-474`
  - gt/ge/lt/le validation identical except operator and message.
  - **Fix:** Drive from comptime array of constraint descriptors.

- [ ] **#23 `insufficientScopeResponse` duplication (Route vs WebSocket)** — `src/core/app.zig:1646-1767`
  - 4 auth response functions (~170 combined lines, ~90% identical).
  - **Fix:** Extract shared helper parameterized by option type.

- [ ] **#24 `normalize*Sink` + `is*SinkType` duplication (10 funcs)** — `src/core/app.zig:1837-1952`
  - 5 normalize + 5 type-check functions, ~100 lines, identical pattern.
  - **Fix:** Single generic `normalizeSink(comptime EventType, comptime checker, sink)`.

- [ ] **#25 `uniqueXxxComponentName` duplication (3 copies)** — `src/openapi/generator.zig:679,813,954`
  - Same algorithm: build base name, check uniqueness, append suffix.
  - **Fix:** Generic `uniqueComponentName(base_builder_fn, has_name_fn, components, allocator)`.

- [ ] **#26 `buildXxxComponentBaseName` duplication (3 copies)** — `src/openapi/generator.zig:704,838,981`
  - Same pattern: ArrayList(u8), appendNormalizedIdentifierPart, trim, toOwnedSlice.
  - **Fix:** Parameterize with the parts to append.

- [ ] **#27 `writeDependenciesArray` two identical 26-line loop bodies** — `src/openapi/generator.zig:1438-1492`
  - `dependencies` and `injected_dependencies` loops are byte-for-byte identical.
  - **Fix:** Extract `writeSingleDependency(writer, dep)`.

- [ ] **#28 O(n^2) linear scans in generator.zig** — multiple locations
  - `appendUniquePath`, `parameterComponentName`, `requestBodyComponentNameByJson`, `lookupSecurityScheme` all use linear scans.
  - **Fix:** Use `StringHashMap` for deduplication.

- [ ] **#29 `setSocketRecvTimeout`/`setSocketSendTimeout` duplication** — `src/runtime/server.zig:286-320`
  - Identical except for `SO.RCVTIMEO` vs `SO.SNDTIMEO`.
  - **Fix:** Single `setSocketTimeout(fd, opt, timeout_ms)` function.

- [ ] **#30 `storeSyntheticHeaders`/`storeRawHeaders` duplication** — `src/http/request.zig:699-724`
  - Nearly identical iteration bodies.
  - **Fix:** Extract shared `storeHeader(self, name, value)` helper.
